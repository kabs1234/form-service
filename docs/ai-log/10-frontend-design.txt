● The current UI is stock shadcn (neutral greys, Geist, identical cards). A
  redesign touches every page and needs a new font package, and CLAUDE.md says
  not to add dependencies without asking. So here's the design plan for you to

  Design plan: "Анкета в тетради"

  Subject. A student career platform. It has two audiences with different jobs.
  Managers need a calm, tool-like admin. Students should see a form that feels
  like an application from a real organisation. The visual language comes from
  the most familiar form in Russian student life, the school notebook (тетрадь):
  - Violet ink (фиолетовые чернила) for primary actions and the data in charts.
  - The red margin line and red pen for required marks and validation errors.
  - A highlighter for the one place that needs attention: the field where
    students quit.

  Color

  ┌─────────────┬─────────┬────────────────────────────────────────────┐
  │    Token    │   Hex   │                    Role                    │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Paper       │ #F6F7F4 │ page background, slightly cool (not cream) │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Sheet       │ #FFFFFF │ the form sheet and the builder preview     │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Ink         │ #3B2A8F │ primary buttons, links, funnel bars        │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Graphite    │ #23252B │ body text                                  │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Red pen     │ #C2362F │ margin rule, required marks, errors        │
  ├─────────────┼─────────┼────────────────────────────────────────────┤
  │ Highlighter │ #F4D24B │ the top drop-off field only                │
  └─────────────┴─────────┴────────────────────────────────────────────┘

  Type
  - Golos Text. A Cyrillic-first UI font made for Russian public services. Used
    for all body text and controls.
  - Unbounded. A wide Cyrillic display face. Used only for page titles and the
    big conversion number. It's the one loud typographic element.
  - No all-caps labels and no eyebrow labels.

  Layout
  Admin list (a register, not cards)        Public form (one sheet)
  ┌──────────────────────────────────┐      ┌─┬──────────────────────┐
  │ Формы                 [+ Новая]  │      │ │ Стажировка в …       │
  ├──────────────────────────────────┤      │1│ ФИО ______________   │
  │ Стажировка 2026  ● опубл.  14  ⧉ ⋯│      │2│ Email ____________   │
  │ Летняя школа     ○ черн.    0    ⋯│      │3│ Почему вы … ______   │
  └──────────────────────────────────┘      └─┴──────────────────────┘
                                         red margin rule, field numbers in the
  margin
  Builder: editor on the left, the preview as the same sheet on the right
  (sticky)
  Analytics: a large conversion number → funnel in violet → drop-off chart with
  the top field highlighted
  - Everything is left-aligned. Cards only appear where content really is a
    separate object.
  - Field numbers are justified because fields are an ordered sequence: the
    builder reorders them. The same number links a field in the builder, the
    form and the drop-off chart ("поле 4").

  Principles
  - The sheet with its red margin is the one memorable element.
  - The admin stays quiet around it.
  - The highlighter appears in exactly one place.

  Checked against the defaults to avoid
  - I rejected cream with terracotta, black with acid green, and the card grid.
  - I first considered a generic SaaS blue for the ink. I replaced it with
    violet because violet comes from the subject itself.

  Changes are limited to styling, layout and some markup. Logic, hooks and the
  API stay as they are. Fonts are self-hosted through Fontsource, so it still
  works offline.
